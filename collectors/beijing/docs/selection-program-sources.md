# 选调／优培独立来源

本文件登记北京站每轮必须检查的选调／优培官方来源。它们与综合公务员考试、事业单位和央国企来源分开建模：公告被发现不等于职位已经可报，更不等于已通过私有资格核验。

| 来源 | 官方入口 | 采集方式 | 本轮完成标准 |
| --- | --- | --- | --- |
| 北京市人力资源和社会保障局选调优培公告 | `https://rsj.beijing.gov.cn/xxgk/tzgg/` | 页面保留该原生入口；后台从北航就业网“公务员／选调生”公开栏目完成分页，只打开北京应届选调／优培标题命中的详情并核验发布机关 | 栏目全部分页、北京标题命中详情和可见附件均有访问证据；报名期或明确预公告进入匿名审核记录 |

## 生命周期与发布边界

1. 报名截止日未过的公告：下载公开职位表后，才可进入私有资格逐项判断。
2. 官方明确的预公告：记录为“职位表/报名期待公布”，持续追踪，但不写成具体可报岗位。
3. 历史公告、录用公示、资格审核和考试流程通知：仅作为来源健康与结构回归样本，不当作在招信息。
4. 任何职位都必须由单独的私有资格流程确认；本公开仓库和审核日志不存放个人身份、户籍、政治面貌等字段。

`node scripts/run-public-exam-sync.mjs --write` 会自动处理该来源；它与国考、市考同走公告采集、期限判断、匿名审核记录和门禁验证链路。
