# 四城采集器

本目录是统一服务的采集运行时，不是四个独立部署站点。

```text
collectors/
├── beijing/    北京来源、采集脚本、公开快照与门禁
├── shanghai/   上海来源、采集脚本、公开快照与门禁
├── guangzhou/  广州来源、采集脚本、公开快照与门禁
└── shenzhen/   深圳来源、采集脚本、公开快照与门禁
```

根目录的 `scripts/run-all-cities-sync.mjs` 依次调用每座城市的 `scripts/run-full-workflow.mjs`，通过该城市门禁后再把 `data/` 快照导入统一 SQLite。网页、收藏、管理员、更新计划和事实日志只由仓库根目录的服务提供。

每座城市保留独立配置，是因为不同政府网站、招聘系统、字段和分页方式需要分别维护采集器；但这些目录都随同一个 Git 仓库版本化、测试和部署。修改某座城市前先阅读其 `AGENTS.md`、`AUTOMATION.md` 和 `data/` 中的来源与筛选规则。
