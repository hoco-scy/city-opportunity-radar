# 选调／优培独立来源

本文件登记广州站每轮必须检查的选调／优培官方来源。广东省的选调公告可能在省级口径发布；在职位表公开前，广州站只保留公告级对象，不凭“广东”标题声称存在广州具体岗位。

| 来源 | 官方入口 | 采集方式 | 本轮完成标准 |
| --- | --- | --- | --- |
| 广州市人力资源和社会保障局选调优培公告 | `https://rsj.gz.gov.cn/ywzt/rszdgg/gwykl/` | 页面保留该原生入口；后台从北航就业网“公务员／选调生”公开栏目筛选广东省应届选调公告，职位表再按广州处理 | 栏目全部分页、广东省标题命中详情和可见附件均有访问证据；报名期或明确预公告进入匿名审核记录 |

## 生命周期与发布边界

1. 报名截止日未过的公告：下载公开职位表后，才可进入私有资格逐项判断。
2. 官方明确的预公告：记录为“职位表/报名期待公布”，持续追踪，但不写成具体可报岗位。
3. 历史公告、录用公示、资格审核和考试流程通知：仅作为来源健康与结构回归样本，不当作在招信息。
4. 任何职位都必须由单独的私有资格流程确认；本公开仓库和审核日志不存放个人身份、户籍、政治面貌等字段。

`node scripts/run-public-exam-sync.mjs --write` 会自动处理该来源；它与国考、市考同走公告采集、期限判断、匿名审核记录和门禁验证链路。
