# 选调／优培独立来源

本文件登记上海站每轮必须检查的选调／优培来源。上海市应届选调生公告由中共上海市委组织部发布，公告及政策问答按发布规则在选调高校官方网站公开。原先的上海市公务员局“公开遴选／公开选调”专题面向在职公务员，已经从应届生采集范围移除。

| 来源 | 用户快捷入口 | 采集方式 | 本轮完成标准 |
| --- | --- | --- | --- |
| 上海市公务员考试报名系统 | `https://www.shacs.gov.cn/Link/2026018xd.htm`（仅供用户直接访问，不采集、不监控） | 脚本读取北航就业信息网“公务员／选调生”栏目全部公开分页；先按上海应届选调公告标题筛选，再打开详情确认发布机关并保留附件 | 栏目全部分页、标题命中详情和可见附件均有访问证据；报名期或明确预公告进入匿名审核记录 |

## 生命周期与发布边界

1. 报名截止日未过的公告：下载公开职位表后，才可进入私有资格逐项判断。
2. 官方明确的预公告：记录为“职位表/报名期待公布”，持续追踪，但不写成具体可报岗位。
3. 历史公告、录用公示、资格审核和考试流程通知：仅作为来源健康与结构回归样本，不当作在招信息。
4. 任何职位都必须由单独的私有资格流程确认；本公开仓库和审核日志不存放个人身份、户籍、政治面貌等字段。

`node scripts/run-public-exam-sync.mjs --write` 会自动处理该来源；它与国考、市考同走公告采集、期限判断、匿名审核记录和门禁验证链路。标题命中并不等于发布证据：详情未确认中共上海市委组织部、或属于拟录用／公示／考试流程的通知不会进入候选。
